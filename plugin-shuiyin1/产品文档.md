# 水印插件 产品文档

> 版本：**v0.2.12** | 适用 NocoBase 2.x | 文档日期：2026-07-25

---

## 一、产品概述

### 1.1 产品简介

水印插件为 NocoBase 后台管理系统提供全局页面水印功能。在页面最上层覆盖半透明倾斜文字水印，显示当前登录用户身份标识（含用户名和日期时间），有效防止截图泄露敏感信息，满足企业审计合规要求。

### 1.2 核心能力

- 全页面覆盖固定定位水印，不影响页面正常操作
- 自动识别当前登录用户身份（昵称/用户名/邮箱）
- 支持自定义水印文字、透明度、字号、排列密度
- 显示实时日期时间（年月日 时分），每分钟自动刷新
- 防删除机制：水印被手动删除后自动重建
- 配置实时生效：保存设置后无需刷新页面
- 总开关控制：可随时禁用或启用水印，配置不丢失

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| 企业内部管理系统 | 防止员工通过截图泄露业务数据 |
| 敏感数据页面 | 为含客户信息、财务数据的页面增加用户水印追溯 |
| 审计合规要求 | 满足信息安全审计对界面用户标识的要求 |
| 多人共享账号场景 | 通过水印区分实际操作用户，防止账号共用 |

## 二、安装

### 2.1 上传安装（推荐）

1. 在 NocoBase 后台进入 **插件管理** 页面
2. 点击 **上传插件** 按钮
3. 选择 `plugin-shuiyin1-{版本号}.tar.gz` 文件上传
4. **上传后必须重启整个服务才能生效**：
   - Docker 部署：`docker restart <容器名>`
   - 源码部署：重启 Node.js 进程
5. 重启后刷新浏览器，进入 **设置 → 水印设置** 确认功能可用

### 2.2 源码安装

```bash
# 在 NocoBase 应用根目录执行
nb source build
nb plugin enable @my-project/plugin-shuiyin1
```

重启服务后生效。

### 2.3 版本兼容性

- 兼容 NocoBase **2.x** 所有版本
- 同时支持 v1 管理后台（`/admin`）和 v2 管理后台（`/v2`）

## 三、使用指南

### 3.1 首次使用

1. 管理员启用插件并重启服务
2. 刷新 NocoBase 后台页面
3. 页面左上角开始显示当前登录用户昵称的水印（倾斜 30°，半透明黑色文字）

### 3.2 基本水印效果

- **位置**：页面固定定位，覆盖整个视口
- **层级**：最顶层（z-index: 999999），不影响下方内容的点击和操作
- **文字**：默认显示当前用户昵称，未设置昵称则显示用户名或邮箱
- **样式**：倾斜 -30°，黑色文字，半透明（默认 15% 不透明度）
- **密度**：全屏均匀平铺，默认 5 档（最密集，单元格 140×90 px）

### 3.3 自定义水印

进入 **设置 → 水印设置** 页面进行配置：

#### 3.3.1 启用水印（总开关）

- 类型：开关
- 默认：开启
- 作用：关闭后水印立即消失，打开后立即恢复
- 说明：配置不会因关闭而丢失，重新打开即恢复之前的所有设置

#### 3.3.2 水印内容

- 类型：下拉多选（昵称 / 用户名 / 自定义内容）
- 默认：昵称
- 说明：
  - 昵称 → 显示当前登录用户昵称
  - 用户名 → 显示当前登录用户名
  - 自定义内容 → 勾选后出现文本输入框（必填），所有用户看到相同的水印文字
  - 同时勾选多项时，空格分隔同行显示（如「张三 zhangsan」）
  - 文字过长时优先加宽瓦片（上限 3 倍），仍放不下才按比例缩小字号（下限 6px），保证完整显示

#### 3.3.3 透明度

- 类型：数字输入（0.01 ~ 1.00，步长 0.01）
- 默认：0.15
- 说明：
  - 数值越小越透明（0.01 几乎看不见）
  - 数值越大越不透明（1.00 完全不透明）
  - 建议范围：0.10 ~ 0.30，兼顾视觉和可读性

#### 3.3.4 字号

- 类型：数字输入（8 ~ 72，步长 1）
- 默认：10px
- 说明：根据页面内容密度调整，小字号更隐蔽，大字号更醒目

#### 3.3.5 排列密度

- 类型：数字输入（1 ~ 5，步长 1）
- 默认：5（最密集）
- 说明：
  - 1 = 最稀疏（水印间隔大，单元格 400×280 px）
  - 2 = 较稀疏（单元格 320×220 px）
  - 3 = 中等（单元格 240×160 px）
  - 4 = 较密集（单元格 180×120 px）
  - 5 = 最密集（单元格 140×90 px）

#### 3.3.6 显示当前年月日时间

- 类型：开关
- 默认：开启
- 说明：
  - 开启后水印文字末尾追加实时日期时间（格式：`文字 2026-06-30 16:55`）
  - 每分钟自动刷新时间显示
  - 有助于截图溯源时精确定位截图时间

### 3.4 临时关闭水印

1. 进入 **设置 → 水印设置**
2. 将「启用水印」开关关闭
3. 点击 **保存**
4. 页面水印立即消失
5. 需要恢复时，重新打开开关并保存即可

### 3.5 查看水印插件说明文档

浏览器中直接访问：`http://<服务器地址>/api/plugins/@my-project/plugin-shuiyin1/readme`

## 四、技术特性

| 特性分类 | 特性说明 |
|----------|----------|
| 渲染方式 | Canvas 绘制倾斜文字图片，CSS `background-image: repeat` 全屏平铺 |
| 定位方式 | `position: fixed` 固定定位，覆盖全视口 |
| 层级 | `z-index: 999999`，确保在所有页面内容之上 |
| 交互 | `pointer-events: none`，不拦截鼠标和键盘事件 |
| 用户识别 | 优先使用 nickname（昵称），其次 username（用户名），最后 email（邮箱） |
| 防删除 | MutationObserver 实时监听 DOM 变化 + 每 2 秒轮询检测，发现水印 DOM 被移除后自动重建 |
| 配置生效 | 保存配置后通过浏览器 `CustomEvent` 即时通知水印组件重绘，毫秒级生效 |
| 定时刷新 | 每 30 秒重新从服务器拉取配置和当前用户信息，自动更新水印用户标识 |
| 时间刷新 | 显示日期时间模式下，每分钟重绘 Canvas 更新时间字符串 |
| 账号切换 | 退出登录→重新登录后，30 秒内自动更新水印为当前用户信息 |
| 认证页面 | 登录页、注册页、忘记密码页、重置密码页自动跳过水印渲染 |
| 服务重启 | 重启后自动从数据库读取最新配置，不依赖前端缓存 |
| 双端适配 | 同时提供 v1 和 v2 客户端实现，适配不同版本的 NocoBase UI 运行时 |

## 五、安全与限制

### 5.1 安全特性

- 水印包含用户身份标识和时间戳，截图后可追溯到操作者
- 水印全屏覆盖，无法通过滚动或缩放避开
- 防删除机制阻止普通用户通过开发者工具移除水印

### 5.2 已知限制

| 限制 | 说明 |
|------|------|
| 前端渲染 | 水印在浏览器端渲染，高级用户可用开发者工具彻底禁用水印 |
| 不加密 | 水印文字为明文显示，不包含加密信息 |
| 不含导出 | 本插件不处理导出文件（Excel/PDF）的水印添加 |
| 性能影响 | 大量 Canvas 重绘可能对低性能设备有轻微影响，但密度和水印文字复杂度通常不影响 |

### 5.3 安全建议

1. 配合 NocoBase 权限控制系统，对敏感数据表设置精细化访问权限
2. 配合 NocoBase 审计日志功能，记录关键数据操作
3. 对于高度敏感场景，考虑在后端对导出的文件额外添加水印
4. 定期检查水印设置未被未授权修改（设置页的读写权限为所有已登录用户）

## 六、常见问题

### 6.1 保存后水印没有变化

1. 确认提示"保存成功"后，水印是否仍有变化
2. 打开浏览器控制台（F12），切换到 Console 标签
3. 查看是否有红色报错信息
4. 若无报错，刷新页面重新加载

### 6.2 刷新页面后水印恢复默认

1. 确认插件已正常启用（插件管理页面查看状态）
2. 确认数据库连接正常
3. 打开控制台查看 `[shuiyin1] parsed settings` 日志内容
4. 若配置为空，检查数据库 `shuiyin1_settings` 表中是否有数据记录

### 6.3 水印显示的是用户名而非自定义文字

水印内容未勾选「自定义内容」时按所选来源（昵称/用户名）显示。勾选「自定义内容」并填写文字保存后即可替换。

### 6.4 水印影响页面操作

水印层内置了 `pointer-events: none` 样式，鼠标点击会穿透水印层到达下方元素。如有异常，请检查是否引入了覆盖此样式的自定义 CSS。

### 6.5 注销后重新登录水印消失

这是预期行为。插件在检测到进入登录页时会移除水印。登录成功后 30 秒内会自动重建水印（等待周期性刷新触发），或手动刷新浏览器即刻显示。

### 6.6 水印文字太小/太大看不清

调整「字号」参数（8 ~ 72），通常 10 ~ 16 效果最佳，同时可配合调整「排列密度」优化显示效果。

### 6.7 水印太密集/太稀疏

调整「排列密度」参数（1 ~ 5），1 最稀疏适合大屏，5 最密集适合防截图场景。
