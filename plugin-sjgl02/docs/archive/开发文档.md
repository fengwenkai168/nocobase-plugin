## 1. 功能需求说明

### 1.1 产品定位

sjgl02 是一个面向 NocoBase 的**企业级数据管理插件**，提供以下核心能力：

- **大规模数据导入**：支持 Excel（xlsx/xls/csv）批量导入，单次最高 50 万行
- **灵活数据导出**：支持百万级数据导出，关联表独立 Sheet/文件导出，附件打包
- **任务管理**：导入/导出任务异步执行，支持进度追踪、取消、重试、下载
- **表级权限控制**：自定义用户/角色在特定数据表上的导入/导出权限，细粒度控制字段、模式、唯一值

### 1.2 核心功能模块

#### 1.2.1 数据导入

**用户旅程（3 步向导）**：

**Step 1: 选择数据表 & 上传文件**
- 用户从有导入权限的数据表列表中选择目标表
- 上传 Excel 文件（支持 .xlsx ≤50 万行、.xls ≤20 万行、.csv）
- 系统校验文件格式、大小、行数上限

**Step 2: 配置映射**
- **Sheet & 表头设置**：选择 Sheet 名称、表头行号
- **权限切换**：选择本次导入使用的权限配置（用户自定义权限/角色权限）
  - admin/root 可切换任意权限配置
  - 普通用户只能用自己的权限配置
  - 权限配置决定：可用导入模式、唯一值字段预填、可导入字段范围
- **导入模式选择**：
  - `insert`（仅新增）：所有行作为新记录插入
  - `update`（仅更新）：根据唯一值字段匹配已有记录，仅更新匹配到的记录
  - `upsert`（新增+更新）：匹配到则更新，匹配不到则新增
  - 模式由选中的权限配置锁定（单模式锁定只读，多模式可切换）
- **唯一值字段**：更新/upsert 模式必须至少选 1 个，最多 3 个
  - 权限已配置 → 预填锁定
  - 权限未配置 → 自由选择
- **字段映射**：将 Excel 列映射到数据表字段
  - 每列可选：Excel 列名（自动映射）/ 自定义内容（固定值）/ 忽略
  - 仅显示权限配置中"可导入"的字段
  - 自动匹配：根据列名智能匹配字段
- **空白字段处理**：
  - 按 Excel 更新（清空）：Excel 为空则清空数据库字段
  - 不更新（保留原值）：Excel 为空则跳过该字段
- **多对多空值策略**（更新/upsert 模式）：
  - 清空关联：Excel 为空时删除所有关联记录
  - 保留原关联：Excel 为空时保持原有关联不变
- **附件导入**：可选上传 `attachments.tar.gz`，Excel 填文件名，系统自动关联

**Step 3: 预览 & 执行**
- 展示配置摘要卡片（行数、模式、唯一值、附件等）
- 预览前 10 行数据（表头显示：Excel 列名 → 数据表字段 + 标签）
- 点击"执行导入"→ 创建后台任务，跳转任务管理页

**技术特性**：
- **严格模式单大事务**：50 万行在一个事务中执行，任意行失败全部回滚
- **WorkbookReader 流式读取**：内存峰值 ~650 MB，避免 OOM
- **空值唯一值预检**：更新/upsert 模式下，任何行唯一值为空 → 整批回滚
- **系统字段智能处理**：createdAt/updatedAt/createdBy/updatedBy 优先使用 Excel 映射值，未映射则系统自动填充
- **主键动态识别**：不写死 `id`，运行时获取目标表实际主键名和类型

#### 1.2.2 数据导出

**用户旅程（3 步向导）**：

**Step 1: 选择数据表**
- 用户从有导出权限的数据表列表中选择目标表
- admin/root 可见"全部数据表（含系统表）"选项

**Step 2: 选择字段 & 配置**
- **字段选择**：
  - 全选/全不选
  - 按字段类型筛选（文本/数字/日期/关联/附件等）
  - 仅显示权限配置中"可导出"的字段
- **关联字段处理**：
  - 显示值：导出关联记录的显示字段（如用户名）
  - 仅 ID：导出关联记录的主键值
- **关联表导出**：
  - 不导出关联表
  - 导出为独立 Sheet（关联表数据追加到主表 xlsx 的其他 Sheet）
  - 导出为独立文件（关联表数据导出为独立 xlsx，最终打包 tar.gz）
- **附件导出**：是否打包附件为 `attachments.tar.gz`
- **日期时间格式**：ISO 8601 / YYYY-MM-DD HH:mm:ss / 自定义格式
- **超大数据集分表**：百万行以上自动分表（每 100 万行一个 Sheet）

**Step 3: 执行导出**
- 点击"执行导出"→ 创建后台任务，跳转任务管理页

**技术特性**：
- **游标分页 + WorkbookWriter 流式写入**：100 万行内存增长仅 58 MB
- **无行数上限**：理论支持无限行数导出
- **fs.createReadStream 响应**：避免大文件全部加载进内存

#### 1.2.3 任务管理

**任务列表**：
- 展示全部导入/导出任务（用户仅看自己的任务，admin 看全部）
- 列表字段：任务 ID、类型（导入/导出）、数据表、状态、进度、创建时间、完成时间、操作人
- 筛选：按类型、状态、数据表、时间范围筛选
- 状态：
  - `pending`（待执行）
  - `running`（执行中）
  - `completed`（已完成）
  - `failed`（失败）
  - `cancelled`（已取消）

**任务详情（右侧抽屉）**：
- **KPI 卡片**：总行数、成功行数、失败行数、进度百分比、耗时
- **配置详情**：数据表、模式、唯一值、字段映射、空白处理等（斑马纹列表）
- **进度日志**：实时流式更新（每 5000 行记录一次）
- **错误日志**：失败行号、字段、错误原因（表格展示，可导出）
- **操作按钮**：
  - 取消（pending/running）：触发事务回滚
  - 重试（failed）：使用相同配置重新执行
  - 下载结果文件（completed 导出任务）
  - 删除任务（completed/failed/cancelled）

**技术特性**：
- **Bull 队列 + Redis**：任务异步执行，支持并发控制、优先级、延迟
- **WebSocket 实时推送**：进度、日志、状态变更实时推送到前端
- **取消 = 事务回滚**：running 任务取消时，触发数据库事务 rollback（<10ms）

#### 1.2.4 权限管理

**权限配置对象**：
- **用户级权限**：为特定用户配置在特定数据表上的权限
- **角色级权限**：为特定角色配置在特定数据表上的权限

**权限配置内容**：
- **可导入模式**：`insert` / `update` / `upsert`（多选）
- **可导出**：是否允许导出该表
- **唯一值字段预设**：导入时预填的唯一值字段（最多 3 个）
- **可导入字段**：允许导入的字段列表（白名单）
- **可导出字段**：允许导出的字段列表（白名单）

**权限列表页**：
- 左侧边栏：用户列表 + 角色列表
- 右侧主区：选中用户/角色的权限配置卡片
  - 卡片显示：数据表名、导入模式、导出开关、唯一值、字段范围
  - 操作：编辑、删除
- 新增权限：选择目标（用户/角色）、数据表，配置权限内容

**权限继承与优先级**：
- 用户权限 > 角色权限
- 用户未配置某表权限时，继承其角色的权限
- 用户配置了某表权限，则完全覆盖角色权限（不合并）

**权限操作日志**：
- 通过数据库 hook 自动记录权限配置的创建/修改/删除
- 记录字段：操作人、操作类型、目标用户/角色、数据表、变更内容、时间
- 仅 admin/root 可查看日志

### 2.3 百万级数据处理策略（基于 spike-results.md）

#### 2.3.1 导入策略

**核心结论**：
- **必须使用 WorkbookReader（V2）**，禁止使用 `workbook.xlsx.read`（V1）
- V1 全量加载内存峰值 1,671 MB，在 2 GB 服务器上会 OOM
- V2 流式读取内存峰值 649 MB，在 2 GB 服务器上可用

**实现方案**：

```typescript
import ExcelJS from 'exceljs';

async function* readExcelStream(filePath: string, sheetName: string, headerRow: number) {
  const workbookReader = new ExcelJS.stream.xlsx.WorkbookReader(filePath, {
    sharedStrings: 'cache', // 缓存共享字符串表
    worksheets: 'emit',     // 逐 sheet emit
  });

  for await (const worksheetReader of workbookReader) {
    if (worksheetReader.name !== sheetName) continue;

    let rowIndex = 0;
    let headers: string[] = [];

    for await (const row of worksheetReader) {
      rowIndex++;
      if (rowIndex === headerRow) {
        headers = row.values as string[];
        continue;
      }
      if (rowIndex <= headerRow) continue;

      // yield 行数据对象
      const rowData: Record<string, any> = {};
      row.eachCell((cell, colNumber) => {
        rowData[headers[colNumber]] = cell.value;
      });
      yield rowData;
    }
  }
}

// 批量写入
async function importWithTransaction(
  dataSource: AsyncIterable<Record<string, any>>,
  targetCollection: string,
  batchSize = 5000
) {
  const transaction = await sequelize.transaction();
  try {
    let batch: any[] = [];
    for await (const row of dataSource) {
      batch.push(row);
      if (batch.length >= batchSize) {
        await Model.bulkCreate(batch, { transaction });
        batch = [];
      }
    }
    if (batch.length > 0) {
      await Model.bulkCreate(batch, { transaction });
    }
    await transaction.commit();
  } catch (error) {
    await transaction.rollback(); // <10ms
    throw error;
  }
}
```

**性能指标**（50 万行）：
- 读取+写入耗时：59 秒
- 内存峰值：649 MB
- commit 耗时：8 ms
- rollback 耗时：9 ms

**硬上限**：
- xlsx：50 万行
- xls：20 万行（xls 格式限制）
- csv：50 万行

#### 2.3.2 导出策略

**核心结论**：
- 游标分页 + WorkbookWriter 流式写入，内存恒定（100 万行仅增长 58 MB）
- 无行数上限
- 最终文件用 `fs.createReadStream` 响应，避免全部加载进内存

**实现方案**：

```typescript
import ExcelJS from 'exceljs';
import fs from 'fs';

async function exportWithStream(
  collectionName: string,
  fields: string[],
  outputPath: string
) {
  const workbook = new ExcelJS.stream.xlsx.WorkbookWriter({
    filename: outputPath,
    useStyles: true,
    useSharedStrings: true,
  });

  const worksheet = workbook.addWorksheet(collectionName);

  // 写入表头
  worksheet.addRow(fields);

  // 游标分页查询
  const cursor = await repository.find({
    limit: 5000,
    offset: 0,
  });

  let offset = 0;
  while (true) {
    const rows = await repository.find({
      fields,
      limit: 5000,
      offset,
    });
    if (rows.length === 0) break;

    for (const row of rows) {
      worksheet.addRow(fields.map(f => row[f]));
    }

    offset += rows.length;
  }

  await workbook.commit();
}

// Koa 响应
ctx.body = fs.createReadStream(outputPath);
ctx.set('Content-Type', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
ctx.set('Content-Disposition', `attachment; filename="${filename}"`);
```

**性能指标**（100 万行）：
- 查询耗时：36.8 秒
- 写入耗时：2.6 秒
- 总耗时：39.5 秒
- 内存增长：58 MB（255-312 MB 区间波动）
- 文件大小：27.41 MB

**分表策略**（100 万行以上）：
- 每 100 万行一个 Sheet（Sheet1, Sheet2, ...）
- 或每 100 万行一个独立 xlsx（打包 tar.gz）

### 2.4 任务队列架构

**Bull 配置**：

```typescript
import Bull from 'bull';

const importQueue = new Bull('sjgl02:import', {
  redis: {
    host: process.env.REDIS_HOST || 'localhost',
    port: parseInt(process.env.REDIS_PORT || '6379'),
  },
  defaultJobOptions: {
    attempts: 1,           // 不自动重试（失败由用户手动重试）
    removeOnComplete: false, // 保留完成任务（用户可查看）
    removeOnFail: false,    // 保留失败任务
  },
});

// 并发控制
importQueue.process(3, async (job) => {
  return await importWorker(job);
});

// 进度更新
async function importWorker(job: Bull.Job) {
  const { taskId, config } = job.data;
  
  let processedRows = 0;
  for await (const batch of readBatches(config)) {
    await importBatch(batch, config);
    processedRows += batch.length;
    
    // 更新进度
    await job.progress((processedRows / totalRows) * 100);
    
    // WebSocket 推送
    io.to(`task:${taskId}`).emit('progress', {
      taskId,
      progress: processedRows / totalRows,
      processedRows,
    });
  }
  
  return { success: true, processedRows };
}
```

**任务取消机制**：

```typescript
importQueue.on('active', (job) => {
  // 注册取消监听
  const checkInterval = setInterval(async () => {
    const task = await TaskModel.findByPk(job.data.taskId);
    if (task.status === 'cancelled') {
      clearInterval(checkInterval);
      await job.moveToFailed(new Error('User cancelled'), true);
      
      // 触发事务回滚（在 worker 中实现）
      if (job.data.transaction) {
        await job.data.transaction.rollback();
      }
    }
  }, 1000);
});
```

### 2.5 权限检查流程

```
用户发起导入请求
    ↓
获取目标数据表 collectionName
    ↓
查询用户权限配置（targetType='user', targetId=userId, collectionName）
    ↓
存在？ ─No→ 查询用户角色权限配置（targetType='role', targetId=roleId）
    ↓ Yes              ↓
用户权限配置      角色权限配置 ─No→ 拒绝访问（403）
    ↓                  ↓ Yes
    └──────合并────────┘
              ↓
检查请求参数是否符合权限约束：
  - 导入模式 in 可导入模式
  - 映射字段 ⊆ 可导入字段
  - 唯一值字段 = 预设唯一值（若已配置）
              ↓
         通过？ ─No→ 拒绝访问（403）
              ↓ Yes
         执行导入
```

```typescript
// src/server/collections/sjgl02Permissions.ts
export default {
  name: 'sjgl02Permissions',
  fields: [...],
  hooks: {
    async afterCreate(instance, options) {
      const { context } = options;
      await context.db.getRepository('sjgl02PermissionLogs').create({
        values: {
          action: 'create',
          permissionId: instance.id,
          targetType: instance.targetType,
          targetId: instance.targetId,
          collectionName: instance.collectionName,
          changes: { before: null, after: instance.toJSON() },
          operatorId: context.state.currentUser?.id,
        },
        context,
      });
    },
    
    async afterUpdate(instance, options) {
      const { context } = options;
      const previous = instance._previousDataValues;
      await context.db.getRepository('sjgl02PermissionLogs').create({
        values: {
          action: 'update',
          permissionId: instance.id,
          targetType: instance.targetType,
          targetId: instance.targetId,
          collectionName: instance.collectionName,
          changes: { before: previous, after: instance.toJSON() },
          operatorId: context.state.currentUser?.id,
        },
        context,
      });
    },
    
    async afterDestroy(instance, options) {
      const { context } = options;
      await context.db.getRepository('sjgl02PermissionLogs').create({
        values: {
          action: 'destroy',
          permissionId: instance.id,
          targetType: instance.targetType,
          targetId: instance.targetId,
          collectionName: instance.collectionName,
          changes: { before: instance.toJSON(), after: null },
          operatorId: context.state.currentUser?.id,
        },
        context,
      });
    },
  },
};
```

```typescript
// src/client/pages/ImportWizard/index.tsx
import React, { useState } from 'react';
import { Steps, Button, message } from 'antd';
import { useTranslation } from 'react-i18next';
import Step1SelectTable from './Step1SelectTable';
import Step2ConfigMapping from './Step2ConfigMapping';
import Step3Preview from './Step3Preview';
import { importApi } from '../../services/importApi';
import type { ImportConfig } from '../../types';

const ImportWizard: React.FC = () => {
  const { t } = useTranslation();
  const [currentStep, setCurrentStep] = useState(0);
  const [config, setConfig] = useState<Partial<ImportConfig>>({});

  const steps = [
    { title: t('Select Table & Upload File') },
    { title: t('Config Mapping') },
    { title: t('Preview & Execute') },
  ];

  const handleNext = () => {
    if (currentStep < steps.length - 1) {
      setCurrentStep(currentStep + 1);
    }
  };

  const handlePrev = () => {
    if (currentStep > 0) {
      setCurrentStep(currentStep - 1);
    }
  };

  const handleSubmit = async () => {
    try {
      const result = await importApi.createTask(config as ImportConfig);
      message.success(t('Task created successfully'));
      // 跳转到任务管理页
      window.location.href = `/admin/sjgl02/tasks/${result.taskId}`;
    } catch (error) {
      message.error(t('Failed to create task'));
    }
  };

  return (
    <div className="import-wizard" role="main" aria-label={t('Import Wizard')}>
      <Steps current={currentStep} items={steps} style={{ marginBottom: 24 }} />
      
      {currentStep === 0 && (
        <Step1SelectTable config={config} onChange={setConfig} onNext={handleNext} />
      )}
      {currentStep === 1 && (
        <Step2ConfigMapping config={config} onChange={setConfig} onNext={handleNext} onPrev={handlePrev} />
      )}
      {currentStep === 2 && (
        <Step3Preview config={config} onSubmit={handleSubmit} onPrev={handlePrev} />
      )}
    </div>
  );
};

export default ImportWizard;
```

```typescript
  open: boolean;
  onClose: () => void;
}

  const [task, setTask] = useState<Task | null>(null);
  const [loading, setLoading] = useState(false);

  // WebSocket 实时订阅
  useTaskSubscription(taskId, (data) => {
    setTask((prev) => prev ? { ...prev, ...data } : null);
  });

  useEffect(() => {
    if (open && taskId) {
      loadTask();
    }
  }, [open, taskId]);

  const loadTask = async () => {
    setLoading(true);
    try {
      const result = await taskApi.getDetail(taskId!);
      setTask(result);
    } catch (error) {
      message.error(t('Failed to load task'));
    } finally {
      setLoading(false);
    }
  };

    try {
      await taskApi.cancel(taskId!);
      message.success(t('Task cancelled'));
      loadTask();
    } catch (error) {
      message.error(t('Failed to cancel task'));
    }
  };

  const handleRetry = async () => {
    try {
      const result = await taskApi.retry(taskId!);
      message.success(t('Task retried'));
      window.location.href = `/admin/sjgl02/tasks/${result.newTaskId}`;
    } catch (error) {
      message.error(t('Failed to retry task'));
    }
  };

  if (!task) return null;

  return (

      title={t('Task Detail')}
      open={open}
      onClose={onClose}

        </Col>

          <Card>
            <div>{t('Success Rows')}</div>
            <div style={{ fontSize: 20, fontWeight: 600, color: '#52c41a' }}>{task.successRows}</div>
          </Card>
        </Col>
        <Col span={6}>
          <Card>
            <div>{t('Failed Rows')}</div>
            <div style={{ fontSize: 20, fontWeight: 600, color: '#ff4d4f' }}>{task.failedRows}</div>
          </Card>
        </Col>
        <Col span={6}>
          <Card>
            <div>{t('Progress')}</div>
            <div style={{ fontSize: 20, fontWeight: 600, color: '#1677ff' }}>{task.progress}%</div>
          </Card>
        </Col>
      </Row>

      {/* 配置详情 */}

          <Col span={8}>{t('Collection')}: {task.collectionName}</Col>
          <Col span={8}>{t('Mode')}: {task.config.mode}</Col>

        </Row>
      </Card>

      {/* 进度日志 */}
      <Card title={t('Progress Logs')} style={{ marginBottom: 16 }}>
        <pre style={{ maxHeight: 200, overflow: 'auto' }}>{task.progressLogs}</pre>
      </Card>

      {/* 错误日志 */}
      {task.errorLogs && task.errorLogs.length > 0 && (

          <Table
            dataSource={task.errorLogs}
            columns={[
              { title: t('Row'), dataIndex: 'rowIndex', width: 100 },
              { title: t('Field'), dataIndex: 'field', width: 150 },
              { title: t('Error'), dataIndex: 'error' },
            ]}
            pagination={{ pageSize: 10 }}
            size="small"
          />
        </Card>
      )}

      {/* 操作按钮 */}
      <div style={{ textAlign: 'right' }}>
        {(task.status === 'pending' || task.status === 'running') && (
          <Button onClick={handleCancel} danger aria-label={t('Cancel Task')}>
            {t('Cancel')}
          </Button>
        )}
        {task.status === 'failed' && (
          <Button onClick={handleRetry} type="primary" aria-label={t('Retry Task')}>

          </Button>

        {task.status === 'completed' && task.type === 'export' && (

            aria-label={t('Download Result')}
          >
            {t('Download')}
          </Button>
        )}
      </div>
    </Drawer>
  );
};
```

```typescript
// src/client/hooks/useTaskSubscription.ts
import { useEffect } from 'react';
import { io, Socket } from 'socket.io-client';

let socket: Socket | null = null;

export const useTaskSubscription = (
  taskId: string | null,
  onUpdate: (data: any) => void
) => {
  useEffect(() => {
    if (!taskId) return;

    if (!socket) {
      socket = io({
        path: '/socket.io',
        transports: ['websocket'],
      });
    }

    socket.emit('join-task', { taskId });

    const handleProgress = (data: any) => {
      if (data.taskId === taskId) {
        onUpdate(data);
      }
    };

    const handleStatus = (data: any) => {
      if (data.taskId === taskId) {
        onUpdate(data);
      }
    };

    const handleLog = (data: any) => {
      if (data.taskId === taskId) {
        onUpdate(data);
      }
    };

    socket.on('task:progress', handleProgress);
    socket.on('task:status', handleStatus);
    socket.on('task:log', handleLog);

    return () => {
      socket?.emit('leave-task', { taskId });
      socket?.off('task:progress', handleProgress);
      socket?.off('task:status', handleStatus);
      socket?.off('task:log', handleLog);
    };
  }, [taskId, onUpdate]);
};
```

## 6. 权限控制实现方案

### 6.1 权限模型

**权限对象**：
- **用户级权限**：`sjgl02Permissions.targetType = 'user'`
- **角色级权限**：`sjgl02Permissions.targetType = 'role'`

**权限优先级**：
- 用户权限 > 角色权限
- 用户未配置某表权限 → 继承角色权限
- 用户配置了某表权限 → 完全覆盖角色权限（不合并）

### 6.2 权限检查服务

```typescript
// src/server/services/PermissionService.ts
import { Context } from '@nocobase/actions';

export class PermissionService {
  /**
   * 获取用户在指定数据表上的权限配置
   * @param userId 用户 ID
   * @param collectionName 数据表名
   * @returns 权限配置或 null
   */
  async getUserPermission(userId: number, collectionName: string, context: Context) {
    const db = context.db;

    // 1. 查询用户级权限
    const userPermission = await db.getRepository('sjgl02Permissions').findOne({
      filter: {
        targetType: 'user',
        targetId: userId,
        collectionName,
      },
    });

    if (userPermission) {
      return userPermission;
    }

    // 2. 用户未配置，查询角色级权限
    const user = await db.getRepository('users').findOne({
      filterByTk: userId,
      appends: ['roles'],
    });

    if (!user || !user.roles || user.roles.length === 0) {
      return null; // 无角色，无权限
    }

    // 3. 查询用户所有角色的权限配置（取并集）
    const roleIds = user.roles.map((r: any) => r.id);
    const rolePermissions = await db.getRepository('sjgl02Permissions').find({
      filter: {
        targetType: 'role',
        targetId: { $in: roleIds },
        collectionName,
      },
    });

    if (rolePermissions.length === 0) {
      return null;
    }

    // 4. 合并多个角色权限（取并集）
    return this.mergeRolePermissions(rolePermissions);
  }

  /**
   * 合并多个角色权限（取并集）
   */
  private mergeRolePermissions(permissions: any[]): any {
    const merged = {
      importModes: new Set<string>(),
      canExport: false,
      uniqueFields: new Set<string>(),
      importableFields: new Set<string>(),
      exportableFields: new Set<string>(),
    };

    for (const perm of permissions) {
      // 导入模式：并集
      perm.importModes?.forEach((mode: string) => merged.importModes.add(mode));

      // 导出权限：任意角色允许即允许
      if (perm.canExport) {
        merged.canExport = true;
      }

      // 唯一值字段：并集
      perm.uniqueFields?.forEach((field: string) => merged.uniqueFields.add(field));

      // 可导入字段：并集（空数组表示全部，取最宽松）
      if (!perm.importableFields || perm.importableFields.length === 0) {
        merged.importableFields.clear(); // 全部字段
      } else if (merged.importableFields.size > 0) {
        perm.importableFields.forEach((field: string) => merged.importableFields.add(field));
      }

      // 可导出字段：并集（同上）
      if (!perm.exportableFields || perm.exportableFields.length === 0) {
        merged.exportableFields.clear();
      } else if (merged.exportableFields.size > 0) {
        perm.exportableFields.forEach((field: string) => merged.exportableFields.add(field));
      }
    }

    return {
      importModes: Array.from(merged.importModes),
      canExport: merged.canExport,
      uniqueFields: Array.from(merged.uniqueFields),
      importableFields: merged.importableFields.size === 0 ? [] : Array.from(merged.importableFields),
      exportableFields: merged.exportableFields.size === 0 ? [] : Array.from(merged.exportableFields),
    };
  }

  /**
   * 检查用户是否有导入权限
   */
  async checkImportPermission(
    userId: number,
    collectionName: string,
    mode: string,
    fields: string[],
    context: Context
  ): Promise<{ allowed: boolean; reason?: string }> {
    // admin/root 用户跳过权限检查
    if (await this.isAdmin(userId, context)) {
      return { allowed: true };
    }

    const permission = await this.getUserPermission(userId, collectionName, context);

    if (!permission) {
      return { allowed: false, reason: 'No permission configured for this collection' };
    }

    // 检查导入模式
    if (!permission.importModes.includes(mode)) {
      return { allowed: false, reason: `Import mode "${mode}" not allowed` };
    }

    // 检查字段权限
    if (permission.importableFields.length > 0) {
      const invalidFields = fields.filter((f) => !permission.importableFields.includes(f));
      if (invalidFields.length > 0) {
        return { allowed: false, reason: `Fields not allowed: ${invalidFields.join(', ')}` };
      }
    }

    return { allowed: true };
  }

  /**
   * 检查用户是否有导出权限
   */
  async checkExportPermission(
    userId: number,
    collectionName: string,
    fields: string[],
    context: Context
  ): Promise<{ allowed: boolean; reason?: string }> {
    if (await this.isAdmin(userId, context)) {
      return { allowed: true };
    }

    const permission = await this.getUserPermission(userId, collectionName, context);

    if (!permission || !permission.canExport) {
      return { allowed: false, reason: 'Export not allowed for this collection' };
    }

    if (permission.exportableFields.length > 0) {
      const invalidFields = fields.filter((f) => !permission.exportableFields.includes(f));
      if (invalidFields.length > 0) {
        return { allowed: false, reason: `Fields not allowed: ${invalidFields.join(', ')}` };
      }
    }

    return { allowed: true };
  }

  /**
   * 判断用户是否为 admin/root
   */
  async isAdmin(userId: number, context: Context): Promise<boolean> {
    const user = await context.db.getRepository('users').findOne({
      filterByTk: userId,
      appends: ['roles'],
    });

    if (!user || !user.roles) return false;

    return user.roles.some((role: any) => role.name === 'admin' || role.name === 'root');
  }

  /**
   * 获取用户可导入的数据表列表
   */
  async getImportableCollections(userId: number, context: Context): Promise<string[]> {
    if (await this.isAdmin(userId, context)) {
      // admin 返回全部数据表
      return context.db.collections.map((c) => c.name);
    }

    const permissions = await context.db.getRepository('sjgl02Permissions').find({
      filter: {
        $or: [
          { targetType: 'user', targetId: userId },
          { targetType: 'role', targetId: { $in: await this.getUserRoleIds(userId, context) } },
        ],
        importModes: { $ne: [] },
      },
    });

    return [...new Set(permissions.map((p: any) => p.collectionName))];
  }

  /**
   * 获取用户可导出的数据表列表
   */
  async getExportableCollections(userId: number, context: Context): Promise<string[]> {
    if (await this.isAdmin(userId, context)) {
      return context.db.collections.map((c) => c.name);
    }

    const permissions = await context.db.getRepository('sjgl02Permissions').find({
      filter: {
        $or: [
          { targetType: 'user', targetId: userId },
          { targetType: 'role', targetId: { $in: await this.getUserRoleIds(userId, context) } },
        ],
        canExport: true,
      },
    });

    return [...new Set(permissions.map((p: any) => p.collectionName))];
  }

  /**
   * 获取用户角色 ID 列表
   */
  private async getUserRoleIds(userId: number, context: Context): Promise<number[]> {
    const user = await context.db.getRepository('users').findOne({
      filterByTk: userId,
      appends: ['roles'],
    });

    if (!user || !user.roles) return [];
    return user.roles.map((r: any) => r.id);
  }
}
```

```typescript
import { Context, Next } from '@nocobase/actions';
import { PermissionService } from '../services/PermissionService';

export async function checkImportPermission(ctx: Context, next: Next) {
  const { collectionName, config } = ctx.request.body;
  const userId = ctx.state.currentUser?.id;

  if (!userId) {
    ctx.throw(401, 'Unauthorized');
  }

  const permissionService = new PermissionService();
  const fields = Object.values(config.fieldMapping || {})
    .filter((m: any) => m.type === 'field')
    .map((m: any) => m.target);

  const result = await permissionService.checkImportPermission(
    userId,
    collectionName,
    config.mode,
    fields,
    ctx
  );

  if (!result.allowed) {
    ctx.throw(403, result.reason);
  }

  await next();
}

export async function checkExportPermission(ctx: Context, next: Next) {
  const { collectionName, config } = ctx.request.body;
  const userId = ctx.state.currentUser?.id;

  if (!userId) {
    ctx.throw(401, 'Unauthorized');
  }

  const permissionService = new PermissionService();
  const result = await permissionService.checkExportPermission(
    userId,
    collectionName,
    config.fields || [],
    ctx
  );

  if (!result.allowed) {
    ctx.throw(403, result.reason);
  }

  await next();
}
```

```typescript
// src/server/actions/permissions.ts
import { Context } from '@nocobase/actions';
import { PermissionService } from '../services/PermissionService';

export default {
  /**
   * 获取权限配置列表
   */
  async list(ctx: Context, next: Next) {
    const { targetType, targetId } = ctx.request.query;
    const repository = ctx.db.getRepository('sjgl02Permissions');

    const permissions = await repository.find({
      filter: { targetType, targetId },
      appends: ['createdBy', 'updatedBy'],
      sort: ['-createdAt'],
    });

    ctx.body = permissions;
    await next();
  },

  /**
   * 创建权限配置
   */
  async create(ctx: Context, next: Next) {
    const data = ctx.request.body;
    const userId = ctx.state.currentUser?.id;

    // 检查是否为 admin
    const permissionService = new PermissionService();
    if (!(await permissionService.isAdmin(userId, ctx))) {
      ctx.throw(403, 'Only admin can create permissions');
    }

    // 检查唯一约束
    const existing = await ctx.db.getRepository('sjgl02Permissions').findOne({
      filter: {
        targetType: data.targetType,
        targetId: data.targetId,
        collectionName: data.collectionName,
      },
    });

    if (existing) {
      ctx.throw(400, 'Permission already exists for this target and collection');
    }

    const permission = await ctx.db.getRepository('sjgl02Permissions').create({
      values: {
        ...data,
        createdById: userId,
        updatedById: userId,
      },
    });

    ctx.body = permission;
    await next();
  },

  /**
   * 更新权限配置
   */
  async update(ctx: Context, next: Next) {
    const { id } = ctx.params;
    const data = ctx.request.body;
    const userId = ctx.state.currentUser?.id;

    const permissionService = new PermissionService();
    if (!(await permissionService.isAdmin(userId, ctx))) {
      ctx.throw(403, 'Only admin can update permissions');
    }

    const permission = await ctx.db.getRepository('sjgl02Permissions').update({
      filterByTk: id,
      values: {
        ...data,
        updatedById: userId,
      },
    });

    ctx.body = permission;
    await next();
  },

  /**
   * 删除权限配置
   */
  async destroy(ctx: Context, next: Next) {
    const { id } = ctx.params;
    const userId = ctx.state.currentUser?.id;

    const permissionService = new PermissionService();
    if (!(await permissionService.isAdmin(userId, ctx))) {
      ctx.throw(403, 'Only admin can delete permissions');
    }

    await ctx.db.getRepository('sjgl02Permissions').destroy({
      filterByTk: id,
    });

    ctx.body = { success: true };
    await next();
  },

   */
  async logs(ctx: Context, next: Next) {
    const { permissionId } = ctx.request.query;
    const { page = 1, pageSize = 20 } = ctx.request.query;

    const [logs, count] = await repository.findAndCount({
      filter: permissionId ? { permissionId } : {},
      appends: ['operator'],
      sort: ['-createdAt'],
      offset: (page - 1) * pageSize,
      limit: pageSize,
    });

    ctx.body = { data: logs, meta: { count, page, pageSize } };
    await next();
  },
};
```

### 8.1 NocoBase 系统字段处理规则（详细版）

基于交互原型中的"NocoBase 系统字段处理逻辑"表格：

| 字段类型 | 导入模式:新增 | 导入模式:更新 | 处理逻辑说明 | 失败场景 |
|---------|-------------|-------------|-------------|---------|
| **createdAt** | 忽略（Excel 映射优先） | 保留原值（Excel 映射优先） | 新建时系统自动填当前时间，更新时不改。但映射了 Excel 列就用 Excel 值 | 映射 Excel 且值格式无法解析为日期 |
| **updatedAt** | 忽略（Excel 映射优先） | 忽略（Excel 映射优先） | 不管新增/更新都自动填当前时间。但映射了 Excel 列就用 Excel 值 | 映射 Excel 且值格式无法解析为日期 |
| **createdById** | 忽略（Excel 映射优先） | 保留原值（Excel 映射优先） | 新建时自动填当前操作用户。更新时不改。但映射了 Excel 列就用 Excel 值 | 映射 Excel 且用户 ID 不存在 |
| **updatedById** | 忽略（Excel 映射优先） | 忽略（Excel 映射优先） | 不管新增/更新都自动填当前操作人。但映射了 Excel 列就用 Excel 值 | 映射 Excel 且用户 ID 不存在 |
| **主键字段** | 可选 | 可更新 | 动态获取实际主键名。自增型未映射自动生成，手动型必须映射 | 手动型未映射/值为空/值重复 |
| **单行文本/多行文本** | 直接写入 | 直接覆盖 | 原样存储 | 必填字段为空且空白策略为"清空" |
| **整数/数字** | 类型转换 | 类型转换 | 自动转换文本为数字 | 无法转换/必填为空 |
| **单选/多选** | 标签匹配 | 标签匹配 | Excel 填显示名称，多选逗号分隔 | 选项名称不存在/必填为空 |
| **布尔值** | 智能转换 | 智能转换 | 识别 true/false、是/否、1/0 等 | 无法识别为布尔值 |
| **日期时间** | 格式解析 | 格式解析 | 识别多种格式（ISO/时间戳/Excel 序列号） | 格式无法识别/必填为空 |
| **多对一(m2o)** | 按主键关联 | 按主键更新 | Excel 填关联记录主键值 | 主键值不存在/类型不匹配 |
| **一对多/多对多** | 全量替换 | 全量替换（可配置保留） | Excel 填多个主键逗号分隔，全量替换关联 | 任意主键值不存在 |
| **附件** | 从 tar.gz 上传 | 从 tar.gz 上传 | Excel 填文件名，从压缩包中找文件上传 | 文件不存在/未上传压缩包/格式不允许 |
| **子表格/子表单** | 忽略 | 忽略 | 不支持导入 | 无 |
| **公式/计算** | 忽略 | 忽略 | 系统自动计算 | 无 |
