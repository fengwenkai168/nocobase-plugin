```
  📁 客户(customers)
  📁 角色(roles)
  📁 权限(permissions)
  ... 系统中的所有表
```

**系统逻辑**：
```typescript
if (currentUser.role === 'admin' || currentUser.role === 'root') {
  // Admin/Root 显示全部表 + 特殊选项
  collections = await getAllCollections();
  collections.unshift({
    name: '__all__',
    title: '全部数据表（含系统表）',
    isSpecial: true,
  });
} else {
  // 普通用户只显示有导出权限的表
  collections = await getCollectionsWithExportPermission(userId);
}
```

**底部提示**：
- 💡 仅显示您有权限导出的数据表
- 📊 共 X 张表可供选择
- ⭐ "全部数据表（含系统表）"仅 admin/root 可见

**确认点**：
- ✅ **仅导出功能有**"全部数据表"特殊选项
- ✅ Admin/Root 可以导出所有表
- ✅ 普通用户受权限配置约束

**B.2 关联字段处理** ⭐ 已优化

```
┌────────────────────────────────────────┐
│ 🔗 关联字段处理                          │
│                                        │
│ 客户(customerId) [多对一]:             │
│   ⭕ 显示值（客户名称）                  │
│   ⭕ 主键值（customerId）               │
│   ⭕ 显示值+主键值（客户名称+customerId）│
│                                        │
│ 产品列表(productIds) [多对多]:          │
│   ⭕ 显示值（产品名称，逗号分隔）         │
│   ⭕ 主键值（ID列表，逗号分隔）          │
│   ⭕ 显示值+主键值（名称+ID，逗号分隔）  │
└────────────────────────────────────────┘
```

**选项说明**：
1. **显示值**：导出关联记录的显示字段（如 "XX公司"）
2. **主键值**：导出关联记录的主键 ID（如 "123"）
3. **显示值+主键值**：同时导出（如 "XX公司(123)"）

**Excel 输出示例**：
```
| 订单号  | 客户（显示值）    | 客户（主键值） | 客户（显示值+主键值）  |
|---------|------------------|----------------|----------------------|
| ORD001  | XX公司           | 123            | XX公司(123)          |
| ORD002  | YY集团           | 456            | YY集团(456)          |
```

**确认点**：
- ✅ 增加了第三个选项"显示值+主键值"
- ✅ 三个选项互斥（单选）
- ✅ 适用于所有关联字段类型
