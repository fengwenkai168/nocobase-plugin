## 1. 产品概述

**数据管理插件** 是面向 NocoBase 平台的数据导入/导出解决方案，为管理员和业务用户提供一站式的数据操作体验。插件同时提供 v1（传统管理后台）和 v2（新一代 UI）两套客户端界面，功能完全一致。

### 1.1 解决的核心问题

| 痛点 | 方案 |
|------|------|
| 业务数据批量录入效率低 | Excel 导入（xlsx/xls/csv），支持字段映射、新增/更新/新增+更新三种模式，百万行流式处理 |
| 数据导出格式不灵活 | Excel 导出（xlsx/ZIP），支持字段筛选、关联表分离导出、附件打包，游标分页百万行导出 |
| 无法追踪导入导出历史 | 任务管理中心，实时进度、执行日志、数据预览、下载链接 |
| 缺乏细粒度权限控制 | 表级权限（用户/角色维度），支持字段白名单、导入模式限制、导出数据范围 |
| 权限变更不可追溯 | 审计日志自动记录每次权限的增删改操作 |

### 1.2 适用角色

| 角色 | 权限概述 |
|------|----------|
| 超级管理员（root） | 全部功能，所有表全权限（系统自动管理），可切换模拟权限方案 |
| 管理员（admin） | 全部功能，所有表全权限（系统自动管理），可切换模拟权限方案 |
| 普通角色/用户 | 受表级权限限制的功能范围（由管理员在权限管理中配置） |

### 1.3 入口说明

| 入口 | 路径 | 模块 |
|------|------|------|
| v1 管理后台 | `/admin/settings/sjgl02` | 导入、导出、任务管理、权限管理（含操作日志） |
| v2 管理后台 | `/v2/admin/settings/sjgl02` | 导入、导出、任务管理、权限管理（含操作日志） |
| v2 页面区块 | 页面 → 添加区块 → 其他 → 数据管理 | 导入、导出、任务管理（不含权限管理） |

## 2. Excel 导入

### 2.1 操作流程

用户通过 3 步向导完成数据导入：

```
Step 1: 选择数据表 → Step 2: 上传文件+字段映射 → Step 3: 预览+执行导入
```

#### Step 1 — 选择数据表

- 下拉选择器中列出当前用户有导入权限的全部数据表
- 表名格式为「表名称（表标识）」，如 `用户（users）`
- 支持输入关键字搜索过滤
- 右侧区域显示导入说明文档

#### Step 2 — 上传文件 & 配置字段映射

**文件上传**

- 点击或拖拽上传 Excel 文件（支持 .xlsx / .xls / .csv）
- 文件大小限制：最大 50MB（由全局设置控制）
- 上传成功后自动解析，显示以下配置项：

| 配置项 | 说明 |
|--------|------|
| Sheet 选择器 | 多 Sheet 文件可选择目标 Sheet；仅 1 个 Sheet 时自动选中并禁用 |
| 表头行号 | 指定 Excel 中第几行为表头（默认 1，可选择 1-100） |
| 预览表头 | 点击按钮弹出对话框，显示 Excel 表头列名 + 前 10 行预览数据 + 行数统计 |
| 导入模式 | 新增 / 更新 / 新增+更新（可选模式受管理员权限限制） |
| 空白单元格处理 | 按Excel值更新 / 按NULL更新 / 跳过（仅 update/upsert 模式可见） |

**特殊说明**：当选择「更新」或「新增+更新」模式时，必须指定至少一个「唯一值字段」用于匹配已有记录。管理员可在权限中预设唯一值字段。

**字段映射表**

核心界面是一个 3 列表格：

```
┌────────────────┬──────────────────┬────────────────────────────┐
│   Excel 列      │     映射方式      │        工作表字段            │
├────────────────┼──────────────────┼────────────────────────────┤
│ 姓名 (下拉选择)  │   Excel列 (只读)   │  姓名 (name) (下拉选择)     │
│ 邮箱 (下拉选择)  │   Excel列 (只读)   │  邮箱 (email) (下拉选择)    │
│ — (未选)       │   忽略 (只读)       │  ID (id) (未映射)          │
│ 角色 (下拉选择)  │   固定值 (只读)     │  角色 (role) → 固定值: 管理员 │
└────────────────┴──────────────────┴────────────────────────────┘
```

关键交互规则：

- **去重联动**：某个 Excel 列已被选择后，其他行的该列自动禁用
- **自动匹配按钮**：点击后按 5 种规则自动匹配 Excel 列与工作表字段（精确匹配 → 标题匹配 → 括号提取 → 包含匹配 → 标题包含）
- **清空按钮**：一键清除所有字段映射
- **必填标记**：管理员配置的必填字段，对应行显示红色 `⚠ 必填` 标签
- **只读字段**：系统自动填充的字段（如 `createdAt`、`updatedAt`）显示 `🔒 只读` 标签，不可映射
- **标题统计**：表格标题栏显示「已映射 N / 忽略 N / 未映射 N」的数量统计

**admin/root 特有功能**：在字段映射区域，admin/root 用户会看到一个「切换权限方案」下拉选择器，可以临时切换到其它用户或角色的权限配置，预览该权限下的导入限制效果。

#### Step 3 — 预览 & 执行

- 显示统计摘要卡片：预计导入行数、错误行数、导入模式、Sheet 名称
- 预览数据表展示前 10 行转换结果
- update/upsert 模式显示唯一值字段提示
- 点击「开始导入」弹出确认对话框，确认后任务提交至服务端执行

### 2.2 导入执行机制

| 特性 | 说明 |
|------|------|
| 事务处理 | 所有数据行在同一个数据库事务中执行，任何失败则全部回滚 |
| 三阶段流式 | 阶段一预校验 → 阶段二写入影子表 → 阶段三分批迁移到真实表 |
| 影子表 | `_sjgl02_import_{taskId}` 临时表，不复制真实表约束，新增 `__import_row_id__` 自增列用于分批 |
| 批次大小 | 阶段三 5000 行/批，按 `__import_row_id__` 键集分页，适合百万级数据 |
| 主键生成 | 未映射主键由 NocoBase 应用层自动生成，支持 Snowflake ID / UUID / Nano ID / 自增整数 |
| 系统字段填充 | 未映射 `createdById` / `updatedById` 时写入导入任务创建人，未映射 `createdAt` / `updatedAt` 时写入当前时间 |
| 主键填写 | Excel 中映射并填写主键时，阶段一检测 Excel 内部重复，阶段三检测与数据库已有记录冲突 |
| 主键不可更新 | `update` / `upsert-update` 模式下主键列不出现在 SET 子句中 |
| 空值唯一值预检 | update/upsert 模式下，任何行的唯一值字段为空 → 整批回滚 |
| 日期转换 | 自动识别 ISO 格式日期（如 `2026-06-29T12:00:00.000Z`）转换为 `YYYY-MM-DD HH:mm:ss` |
| 关联字段 | belongsTo 关联字段通过关联表查询获取外键 ID |
| 同批次去重 | update/upsert 模式同一批次内唯一值重复时拒绝写入 |
| 错误记录 | 失败行记录到任务详情中，含行号 + 错误原因 + 字段快照 |

### 2.3 导入结果查看

导入任务完成后，可在「任务管理」中查看详情，包括：
- 任务摘要（类型、目标表、创建人、时间、状态、数据量）
- 字段映射详情
- 数据预览（成功任务显示前 5 行，失败任务显示错误行详情）
- 执行日志（终端风格的 INFO/SUCC/WARN/ERROR 日志流）
- 下载导入源文件

## 3. Excel 导出

### 3.1 操作流程

```
Step 1: 选择数据表 → Step 2: 选择字段+配置 → Step 3: 执行导出+下载
```

#### Step 1 — 选择数据表

- 下拉首选项「全部数据表（含系统表）」—— 仅 admin/root 用户可见
- 下方列出有导出权限的单个数据表

#### Step 2 — 配置导出

**单表模式（选择一个具体数据表时）**

| 配置项 | 类型 | 说明 |
|--------|------|------|
| 选择字段 | 复选框列表 | 分三组显示：常规字段 / 关联字段（紫色标签）/ 附件字段（青色标签），支持全选/全不选 |
| 关联字段显示 | 下拉 | 每个关联字段可独立选择显示模式：**显示值**（人名等） 或 **仅ID** |
| 关联数据 Sheet | Switch | 开启后，关联表的数据会单独建一个 Sheet（按表分 Sheet） |
| 数据范围 | Radio | **全部数据** / **自定义条件筛选**（条件构建器） |
| 高级选项 | 折叠区 | 文件名模板、包含附件、表头格式 |

高级选项详解：

| 选项 | 说明 |
|------|------|
| 文件名模板 | 默认 `{表名}_{日期}.xlsx`，支持 `{表名}` `{日期}` 两个占位符 |
| 包含附件文件 | 开启后，附件字段的文件与 Excel 打包为 ZIP，附件按字段分文件夹存放 |
| 表头格式 | 三选一：字段名(字段标识) / 字段名 / 字段标识，如 `姓名(name)` / `姓名` / `name` |

**全表模式（选择「全部数据表」时）**

- 显示蓝色警告提示
- 导出标签列表展示所有将被导出的表（含附件标注）
- 没有导出权限的表自动跳过
- 最终打包为一个 ZIP 文件

#### Step 3 — 执行 & 下载

- 显示导出统计摘要和已选字段标签
- 点击「开始导出」后任务转至后台执行
- 进度轮询：每 2 秒自动查询进度，显示进度条和百分比
- 完成后「下载文件」按钮变为可用，点击下载导出文件

### 3.2 导出执行机制

| 特性 | 说明 |
|------|------|
| 流式写入 | 使用 ExcelJS 流式写入器，边查询数据库边写 Excel，内存占用低（~200MB） |
| 无行数限制 | 分页查询（5000 行/批）循环读写，支持百万行级别数据导出 |
| 关联字段取值 | belongsTo/hasOne 按优先级取值：nickname → username → name → email → id |
| 附件打包 | 自动识别 attachment 字段 + FileId 整数字段，从文件系统收集附件并用 archiver 打包为 ZIP |
| 并发防护 | async-mutex 互斥锁确保同时只有一个导出任务在执行 |
| 关联 Sheet | 遍历 belongsTo/hasOne/hasMany/belongsToMany 关联，为每个关联表单独建 Sheet |
| 全表导出 | 逐表检查导出权限，无权限的表自动跳过 |
| 文件存储 | 导出文件通过 NocoBase attachments 表管理，便于下载和审计 |

### 3.3 导出文件格式

| 导出场景 | 输出格式 | 说明 |
|----------|----------|------|
| 单表 + 不包含附件 | .xlsx | 单个 Excel 文件 |
| 单表 + 包含附件 | .zip | 内含 Excel + 按字段分文件夹存放附件 |
| 全表导出 | .zip | 内含每表一个 Excel + 附件 |
| 单表 + 关联 Sheet | .xlsx | 一个 Excel 内含多个 Sheet |

## 4. 任务管理

### 4.1 任务列表

任务管理页面展示所有导入/导出任务的运行状态，提供筛选和搜索功能。

**筛选条件**

| 筛选器 | 选项 |
|--------|------|
| 任务类型 | 全部 / 导入 / 导出 |
| 任务状态 | 全部 / 排队中 / 进行中 / 已完成 / 失败 / 已取消 |
| 搜索 | 支持搜索：任务 ID、文件名、目标表名、创建用户名称 |

**列表列**

| 列名 | 展示方式 |
|------|----------|
| 任务ID | 数字 ID（如 `#1001`） |
| 类型 | 导入（蓝色标签 导入）/ 导出（绿色标签 导出） |
| 目标表 | 表名称（表标识），全表导出显示「全部数据表」 |
| 状态 | 排队中（橙色）/ 进行中（蓝色、旋转动画）/ 已完成（绿色）/ 失败（红色）/ 已取消（灰色） |
| 进度 | 进度条 + 百分比数字 |
| 数据量 | 已处理 / 总数（如 `500 / 1256`） |
| 创建人 | 用户昵称（nickname → username → name 三层兜底显示） |
| 创建时间 | 格式 `YYYY-MM-DD HH:mm:ss` |
| 完成时间 | 已完成/失败/取消的任务显示；进行中显示 `—` |
| 操作 | 「查看」打开详情抽屉 / 「取消」（仅排队中和进行中可见） |

**任务查看范围规则**

- admin/root：始终可查看所有任务
- 普通用户：默认仅查看自己创建的任务
- 如果管理员在设置中将某用户的 `taskViewScope` 设为 `all`，则该用户可查看全部任务

**实时刷新**

进行中的任务自动每 2 秒轮询刷新，完成后停止轮询。

### 4.2 任务详情

点击「查看」打开右侧 Drawer（1024px 宽），展示 7 张信息卡片：

#### 卡片 1：任务摘要

| 信息项 | 内容 |
|--------|------|
| 任务 ID | 数字编号 |
| 任务类型 | 导入 / 导出 |
| 目标表 | 表名称（表标识） |
| 创建人 | 用户名 |
| 创建时间 | 日期时间 |
| 文件信息 | 导入：上传于 xxx / 导出：完成于 xxx |
| 状态 | 当前状态 |
| 数据量 | 已处理 / 总数（含成功/失败数统计） |
| 操作区 | 下载按钮（已完成任务）+ 预览按钮（非 ZIP 文件可用微软在线预览） |

#### 卡片 2：导出字段

- 主表字段 Tab：显示所有导出字段的标签列表
- 关联表字段 Tab：按关联表分组，每个 Tab 显示该表的字段标签
- 每个关联表 Tab 标签格式：`关联字段标题(标识) → 表名称(表标识)`

#### 卡片 3：关联表

- 表格三列：Sheet 名称（Excel 中的实际 Sheet 名）/ 关联表（目标表信息）/ 数据量（实际记录数）

#### 卡片 4：导入配置

- 导入模式：显示标签
- 唯一值字段：Tag 列表（含字段名和标识）
- 必填字段：Tag 列表（含字段名和标识）
- 空白单元格处理模式：显示标签

#### 卡片 5：字段映射

- 表格三列：Excel 列名 / 映射方式（Excel列/固定值/忽略）/ 工作表字段（含自定义值）

#### 卡片 6：数据预览

- 导入任务：显示前 10 行转换数据（成功）/ 显示错误行详情含行号和字段快照（失败，最多 10 条）
- 导出任务：显示导出表的前 5 条数据

#### 卡片 7：执行日志

- 终端风格深色背景（`#1e293b` 深灰色）
- 日志按级别着色：INFO（青色）/ SUCC（绿色）/ WARN（黄色）/ ERROR（红色）
- 带时间戳
- 支持折叠/展开
- 支持独立滚动
- 自动刷新（进行中任务）

### 4.3 取消任务

- 仅「排队中」和「进行中」状态的任务可以取消
- 取消后状态变更为「已取消」，进度保持当前值
- 已完成/失败/已取消的任务不可取消

## 5. 权限管理

### 5.1 页面布局

```
┌──────────────┬──────────────────────────────────────────────────────┐
│   左侧(6列)    │                    右侧(18列)                         │
│              │                                                      │
│  搜索框       │  [✓ 权限配置]  [📋 操作日志]                           │
│              │  目标: 张三 (用户)  |  + 添加权限  🔲全选  🗑批量删除     │
│  ┌─────────┐  │                                                      │
│  │ 用户     │  │  ▼ ✏️ 自定义权限                                      │
│  │ 🔵 张三 │  │  ┌─────────────────────────────────────────────────┐  │
│  │ 🔵 李四 │  │  │ 用户表(users)                     ✏️编辑  🗑删除  │  │
│  │ 🔵 王五 │  │  │ 导入:是 导出:是  新增|更新|新增+更新               │  │
│  └─────────┘  │  │ 唯一值:手机号  必填:姓名|邮箱  可导入:12 可导出:3 │  │
│  ┌─────────┐  │  └─────────────────────────────────────────────────┘  │
│  │ 角色     │  │                                                      │
│  │ 🟢 管理员│  │  ▼ 📦 继承权限（来自: 编辑角色）                       │
│  │ 🟢 编辑  │  │  ┌─────────────────────────────────────────────────┐  │
│  │ 🟢 查看者│  │  │ 商品表(products)                🔍 查看详情       │  │
│  └─────────┘  │  │ 导入:是 导出:否  可导入:5 可导出:0              │  │
│              │  └─────────────────────────────────────────────────┘  │
└──────────────┴──────────────────────────────────────────────────────┘
```

### 5.2 左侧列表

- **用户列表**：蓝色头像 + 用户昵称，显示用户关联的角色
- **角色列表**：绿色头像 + 角色名称（如 `管理员(admin)`）
- 支持关键字搜索过滤
- 点击切换高亮选中

### 5.3 右侧权限卡片

#### 自定义权限卡片

每张卡片展示一条该用户/角色的表级权限规则：

| 卡片元素 | 说明 |
|----------|------|
| 标题 | 表名称（表标识），如 `用户(users)` |
| 操作按钮 | ✏️ 编辑 / 🗑 删除 |
| 标签行 | 导入标签（绿=是/红=否）、导出标签、导入模式标签（Tag 列表）、唯一值字段 Tag、必填字段 Tag、可导入:N个字段、可导出:N个字段 |
| 开关实时保存 | 卡片上的导入/导出开关点击后直接调 API 保存（v1 面板） |

#### 继承权限卡片

继承权限是用户所属角色拥有的权限，标注为紫色 `📦` 标签：
- 不可编辑、不可删除
- 有「查看详情」按钮，弹出只读弹窗查看完整的权限配置
- 如果该表已有自定义权限，继承权限被覆盖（不显示）
- 多角色同表权限自动去重

#### 系统管理权限

admin/root 角色的权限标注为蓝色 `系统管理` 标签：
- 系统自动补齐所有表的权限
- 不可编辑、不可删除
- 导入/导出均为开启状态，所有字段开放

### 5.4 权限编辑弹窗

点击「添加权限」或「编辑」打开 Modal（720px）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 选择数据表 | 下拉搜索 | 是 | 仅显示当前用户/角色尚无自定义权限的表 |
| 允许导入 | Switch | — | 开启后显示导入相关配置 |
| 允许导出 | Switch | — | 开启后显示导出相关配置 |
| 导入模式 | 多选 | 条件必填 | 新增 / 更新 / 新增+更新，可同时选多个 |
| 唯一值字段 | 多选 | 条件必填 | 仅在导入模式含 update/upsert 时显示和必填 |
| 必填字段 | 多选 | — | 从目标表字段中选择 |
| 可导入字段 | 多选 | — | 空 = 全部允许 |
| 可导出字段 | 多选 | — | 空 = 全部允许 |
| 导出筛选 | 条件构建器 | — | 限制导出的数据范围 |

保存逻辑：全量 upsert，即提交的权限列表中不在数据库中的旧记录会被物理删除，同时在审计日志中记录删除操作。

### 5.5 操作日志（审计）

权限管理页面第二个子 Tab `📋 操作日志`，展示 `sjgl02_permission_logs` 表的历史记录：

| 列 | 说明 |
|----|------|
| 操作 | 创建 / 修改 / 删除 / 切换 |
| 目标 | 用户/角色名称 |
| 数据表 | 被操作的表 |
| 操作人 | 执行操作的用户 |
| 操作时间 | 时间戳 |
| 变更详情 | 可展开查看 changes JSON 快照 |

### 5.6 权限优先级规则

```
用户级权限存在 → 使用用户级权限
     ↓ 不存在
角色级权限存在 → 多角色取最宽松（canImport=true 优先，importMode 合并）
     ↓ 不存在
拒绝操作 → 403 Forbidden
```

**特殊情况**：
- admin/root 角色直接短路，跳过所有权限检查，返回全部权限
- 用户级 `canImport=false` 时，无论角色权限如何，该表导入被拒绝
- 前后端一致性：前端 `useTablePermission` hook 和后端 `permission-check.ts` 使用相同的优先级逻辑

### 5.7 权限字段白名单规则

| 权限字段 | 规则 |
|----------|------|
| importFields 为空 | 全部字段可导入 |
| importFields 非空 | 仅白名单内字段可导入（映射表中不可选择白名单外的字段） |
| exportFields 为空 | 全部字段可导出 |
| exportFields 非空 | 仅白名单内字段显示在导出字段选择列表中 |
| uniqueFields | 管理员配置的唯一值字段（前端显示为 Tag，update/upsert 时必选至少 1 个） |
| requiredFields | 管理员配置的必填字段（前端红色 ⚠ 标注，后端强制校验） |

## 13. 常见问题

### Q: 为什么我的用户看不到某个数据表的导入选项？

A: 检查「权限管理」中该用户或所属角色是否有对应该表的 `canImport=true` 权限。注意用户级权限优先级高于角色级，如果用户级 `canImport=false`，即使角色允许也无法导入。

### Q: 导入时为什么某些 Excel 列在下拉中不可选？

A: 字段映射表格有去重联动机制，每列 Excel 列只能被映射一次。请检查该 Excel 列是否已被其他行选择。

### Q: update 模式下为什么明明数据正确却全部失败了？

A: 可能原因：
1. 唯一值字段为空 — 当前版本中 update/upsert 下任意行唯一值空会导致整批回滚
2. 数据库中没有匹配到任何已有记录 — 需要改用 insert 或 upsert 模式

### Q: 管理员看不到全部数据表导出选项？

A: 「全部数据表」导出仅 admin 和 root 角色可见。请确认当前用户具有 admin 或 root 角色。

### Q: 导出包含附件的 ZIP 文件解压后附件在哪里？

A: ZIP 内的附件按字段名分文件夹存放，文件夹名称即为附件字段名（如 `avatar/`、`attachment/` 等）。Excel 中附件列显示系统文件名，可与 ZIP 中文件对应。

### Q: 如何让某个普通用户也能查看全部任务？

A: 在权限管理页面，选中该用户，切换到「设置」区域，将「任务查看范围」设为「全部」。或在数据库 `sjgl02_settings` 表中为该用户创建一条 `userId` 为该用户 ID、`taskViewScope` 为 `all` 的记录。

### Q: 继承权限的修改为何不生效？

A: 继承权限来自角色配置，不能直接修改。请在权限管理左侧切换到对应角色，在角色的自定义权限中修改，或为该用户创建一条自定义权限来覆盖继承权限。

### Q: 任务取消后能恢复吗？

A: 不能。取消后的任务状态不可逆。如果还需要导入/导出数据，请重新创建新任务。
