# 总览

## 1. 产品定位

**plugin-sjgl02（数据管理）** 是一个面向 NocoBase 的高性能数据导入导出插件，核心定位：

- **百万级数据吞吐**：专为单表百万行级别的导入导出场景设计
- **表级精细化权限**：在 NocoBase 原生 ACL 之上提供数据表级和字段级的导入导出权限控制
- **全生命周期管理**：统一的任务模型管理所有导入导出操作的创建、执行、监控和追溯

## 2. 适用场景

| 场景 | 说明 |
|------|------|
| 批量数据导入 | 从 Excel 批量导入业务数据到指定数据表 |
| 批量数据更新 | 按唯一键匹配更新已有数据 |
| 数据全量导出 | 单表/全表导出为 Excel 文件 |
| 数据备份 | 定期全量导出系统数据 |
| 权限控制 | 限制特定角色/用户对特定表的导入导出能力 |

## 4. 数据模型

### 4.1 核心表一览

| 表名 | 说明 | 主要关联 |
|------|------|----------|
| `sjgl02_tasks` | 导入/导出任务表，记录任务状态、进度、配置 | → createdById → 用户 |
| `sjgl02_task_logs` | 任务执行日志表 | → taskId → tasks |
| `sjgl02_table_permissions` | 表级权限配置表（角色级+用户级） | → roleName / userId |
| `sjgl02_permission_logs` | 权限变更审计日志表 | — |
| `sjgl02_settings` | 全局/用户设置表 | → userId |

### 4.2 表关系图

```
sjgl02_tasks ──→ sjgl02_task_logs
     │                   (一对多)
     │ type: import/export
     │ status: pending/processing/completed/failed/cancelled
     │
sjgl02_table_permissions
     │ roleName: 角色级配置（批量）
     │ userId: 用户级配置（优先级高）
     │ tableName: 目标表
     │ allowImport / allowExport / importModes / exportableFields
     │
sjgl02_permission_logs
     │ 记录权限操作的审计信息
```

## 6. 安装与配置

### 6.1 启用插件

```bash
yarn nocobase pm enable @my-project/plugin-sjgl02
```

### 6.2 插件配置项

在 NocoBase 全局设置中可配置：

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 启用表级权限 | true | 是否启用表级导入导出权限控制 |
| 默认允许导入 | true | 未配置权限时的默认行为 |
| 默认允许导出 | true | 同上 |

### 6.3 依赖

- NocoBase >= 2.0.0
- PostgreSQL（依赖 PG 的 `INSERT ON CONFLICT` 等特性）
- exceljs ^4.4.0（Excel 读写引擎）
- archiver ^6.0.0（导出文件打包）
- async-mutex ^0.4.0（并发控制）

## 7. 安全模型

### 7.1 四层权限体系

```
第一层：NocoBase 原生 ACL（系统/全局）
    ↓ 通过则进入
第二层：插件级管理员校验（isAdminOrRoot）
    ↓ 通过则进入（或非 admin 继续下一层）
第三层：表级权限（allowImport / allowExport）
    ↓ 通过则进入
第四层：字段级权限（exportableFields / importModes）
```

### 7.2 认证检查点

| 端点 | 校验方式 | 当前状态 |
|------|----------|----------|
| `import:uploadParse` | 请求内 ctx.state.currentUser | ✅  |
| `import:execute` | 同上 + PermissionService | ✅  |
| `export:create` | isAdminOrRoot + PermissionService | ✅  |
| `export:download` | 无独立校验 | ❌ 已知缺陷 |
| `permissions:save` | 仅排除 admin/root 角色 | ❌ 已知缺陷 |
| `permissions:getSettings` | 无校验 | ❌ 已知缺陷 |
| `tasks:list` | isAdminOrRoot 决定查看范围 | ✅  |

## 8. 百万级核心技术方案

| 技术点 | 实现方式 |
|--------|----------|
| **大文件解析** | exceljs 流式读取，不加载全文到内存 |
| **大文件导出** | 子进程 fork + 游标分页 + stream 写入 |
| **导入安全** | 影子表写入 → 事务性迁移 → 失败回滚 |
| **导出并发控制** | 串行队列 + 僵尸守卫 + 心跳超时 |
| **内存控制** | 每批 500 条，全程内存峰值 < 100MB |
| **取消信号** | DB 状态 + 内存 Set 双重检测 |
