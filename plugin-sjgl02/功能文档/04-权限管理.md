# 权限管理

## 1. 功能概述

提供 NocoBase 原生 ACL 之外的**表级数据权限控制**，核心能力：

- **表级权限**：控制用户能否对某张表执行导入/导出操作
- **字段级权限**：限制用户可导出的字段范围
- **导入模式限制**：控制用户对某张表可使用的导入模式（insert/update/upsert）
- **角色级 + 用户级**：支持按角色批量配置，也支持用户级精确覆盖
- **继承优先级**：用户未配置时继承角色配置，角色也未配置时取默认值
- **审计日志**：所有权限变更操作可追溯

## 2. 用户使用流程

### 2.1 管理员配置权限

1. 管理员进入"数据管理"→"权限管理"面板
2. 默认展示"角色配置"Tab，按角色名搜索
3. 选择目标角色 → 进入该角色的权限配置页面
4. 页面上半部分为"数据表权限列表"（表格形式，每行一张表）：
   - 数据表名称（中文 + 英文）
   - 允许导入（开关）
   - 允许导出（开关）
   - 可导入模式（多选：新增/更新/新增+更新）
   - 可导出字段（多选，从该表字段列表中选择）
5. 修改后点击"保存" → 配置写入 `sjgl02_table_permissions` 表
6. 可切换到"用户配置"Tab，为用户单独覆盖角色级配置

### 2.2 用户级覆盖流程

1. 管理员在"用户配置"Tab 搜索目标用户
2. 为该用户配置与角色级相同的权限字段
3. 用户级配置优先级高于角色级配置
4. 清空用户级配置 = 回退到角色级配置

### 2.3 查看审计日志

1. 管理员进入"审计日志"Tab
2. 列表展示权限变更操作：
   - 时间
   - 操作人
   - 操作类型（创建/修改/删除/切换）
   - 目标（角色/用户）
   - 变更概要（修改了哪些表/字段）
3. 支持按操作人和时间范围过滤

## 3. 权限模型

### 3.1 数据结构

`sjgl02_table_permissions` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer | 主键 |
| roleName | string | 角色名（角色级配置时填写） |
| userId | integer | 用户 ID（用户级配置时填写，优先级高） |
| tableName | string | 目标数据表名 |
| allowImport | boolean | 是否允许导入 |
| allowExport | boolean | 是否允许导出 |
| importModes | string[] | 允许的导入模式列表 |
| exportableFields | string[] | 可导出的字段名列表 |
| createdById | integer | 创建人 |
| updatedAt | datetime | 最后更新时间 |

### 3.2 查询与合并逻辑

```
function getTablePermissions(user, tableName):
    // 1. 先查用户级
    userPerm = findOne({ userId: user.id, tableName })
    if userPerm: return userPerm

    // 2. 再查角色级
    rolePerm = findOne({ roleName: user.role.name, tableName })
    if rolePerm: return rolePerm

    // 3. 返回默认值（全部允许）
    return { allowImport: true, allowExport: true, ... }
```

### 3.3 继承优先级

```
用户级（最高优先级）
    ↓ 未配置时
角色级
    ↓ 未配置时
默认值（全部允许）
```

## 4. 权限检查嵌入点

### 4.1 导入检查点

| 检查点 | 位置 | 校验内容 |
|--------|------|----------|
| 选择目标表 | 前端导入面板 | 使用 `useTablePermission` hook 查询 allowImport |
| 执行导入 | `import-actions.ts` | 调用 `PermissionService` 验证允许导入 |
| 导入模式 | `import-phase3.ts` | 检查所选模式是否在 importModes 列表中 |
| permSource | 跨角色导入 | 按指定角色而非当前用户鉴权 |

### 4.2 导出检查点

| 检查点 | 位置 | 校验内容 |
|--------|------|----------|
| 选择目标表 | 前端导出面板 | 使用 `useTablePermission` hook 查询 allowExport |
| 字段选择 | 前端导出面板 | 根据 exportableFields 控制字段列表显示 |
| 创建导出任务 | `export.ts` | 调用 `isAdminOrRoot` + `PermissionService` |
| Worker 执行 | export-worker.ts | Worker 内再次校验可导出字段列表 |

### 4.3 强制校验工具

`permission-check.ts` 中的 `isAdminOrRoot(ctx)` 用于接口层快速拦截：

```typescript
function isAdminOrRoot(ctx: Context): boolean {
  const role = ctx.state.currentUser?.role;
  return role?.name === 'root' || role?.name === 'admin';
}
```

在部分 action 入口处做白名单式校验：非 admin/root 直接 403。

## 5. 审计日志

所有权限变更（创建/修改/删除）自动写入 `sjgl02_permission_logs` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer | 主键 |
| operator | string | 操作人标识 |
| action | string | 操作类型：create / update / delete / switch |
| targetType | string | 目标类型：role / user |
| targetName | string | 角色名或用户名 |
| summary | text | 变更概要 |
| createdAt | datetime | 操作时间 |

## 6. API 接口

| 端点 | 方法 | 说明 | 鉴权要求 |
|------|------|------|----------|
| `permissions:save` | POST | 保存权限配置 | 当前仅排除 admin/root 角色 |
| `permissions:get` | GET | 查询权限配置 | 同上 |
| `permissions:getSettings` | GET | 查询用户设置 | 无（可指定任意 userId） |
| `permissions:saveSettings` | POST | 保存用户设置 | 无（可指定任意 userId） |
| `permissions:auditLog` | GET | 查询审计日志 | 无 |

### 保存权限

```typescript
POST /api/sjgl02/permissions:save
Body: {
  roleName?: string,
  userId?: number,
  permissions: {
    tableName: string,
    allowImport: boolean,
    allowExport: boolean,
    importModes: string[],
    exportableFields: string[]
  }[]
}
```

### 查询权限

```typescript
GET /api/sjgl02/permissions:get?roleName=member&tableName=posts
RESPONSE: { rows: Permission[], count: number }
```

## 7. 安全边界（已知问题）

| 问题 | 等级 | 说明 |
|------|------|------|
| `savePermissions` 无独立鉴权 | P0 | 仅排除 admin/root 角色，未校验当前用户身份 |
| `getSettings` / `saveSettings` 无鉴权 | P0 | 可指定任意 userId 读写配置 |
| `auditLog` 无鉴权 | P0 | 任意用户可查看审计日志 |
| 批量保存 race condition | P1 | 先读全量再逐条对比修改，并发时可能覆盖 |
| 硬编码 limit 500/200 | P2 | 大租户下用户/角色数可能不够用 |

## 8. 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| allowImport | boolean | true | 默认允许导入 |
| allowExport | boolean | true | 默认允许导出 |
| importModes | string[] | ['insert','update','upsert'] | 默认允许全部模式 |
| exportableFields | string[] | 全部字段 | 默认所有字段可导出 |

## 9. 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 角色配置后用户仍无权限 | 用户级配置可能覆盖了角色级 | 检查用户级配置是否为空 |
| 新增字段后还是导不出 | exportableFields 需要手动添加 | 更新权限配置包含新字段 |
| 模式下拉选项不全 | importModes 配置限制 | 编辑权限，勾选需要的模式 |
| 批量导入后部分配置丢失 | 并发覆盖 | 避免同时多人编辑同一角色的权限 |
